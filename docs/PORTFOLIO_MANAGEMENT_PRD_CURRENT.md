# 组合管理需求文档（当前基线）

最后更新：2026-07-18  
状态：已实现、已上线  
对应代码：`main@0870a73`

## 1. 功能定位

组合管理用于维护用户真实或模拟的持仓、现金、交易计划、份额和净值。模块与股池估值版本联动，但组合数据独立保存。

核心目标：

- 支持多组合和两类账户。
- 记录开仓、加仓、减持、调仓、申购和赎回。
- 打通持仓与股池估值、目标仓位和买卖点。
- 提供盘中估算和日终净值。

## 2. 页面结构

1. 组合切换、资产隐私开关。
2. 开仓、调仓、组合卡片、标签组和更多操作。
3. 持仓 / 净值二级导航。
4. 今日待操作。
5. 资产汇总、标签统计和持仓表格。
6. 净值曲线、基准对比和指标。

## 3. 账户和组合

| 账户 | 可用市场 | 现金 | 净值基准 |
| --- | --- | --- | --- |
| 人民币账户 | A 股、港股通 | CNY | CNY |
| 港美账户 | 港股、美股 | HKD、USD | USD |

需求：

- 创建时必填名称、账户类型和启动金额。
- 同一用户组合名称不可重复。
- 启动金额同时初始化现金、`startBase` 和 `totalUnits`，初始净值为 1。
- 支持初始化导入多行持仓、切换、重命名和删除。
- 删除需二次确认。

## 4. 资产和份额口径

```text
净资产（基准币）= 持仓市值 + 现金
单位净值 = 净资产 / totalUnits
申购或赎回份额 = 原币金额折算基准币 / 操作前单位净值
```

- 申购增加现金和份额；赎回减少现金和份额。
- 赎回不得超过现金，不允许赎回全部份额。
- 现金校准直接覆盖余额，不改变份额，差额进入组合收益。
- 页面汇总金额统一折算为人民币万元；港美账户净值仍按 USD 计算。

## 5. 持仓表格

每行展示：

- 股票名称、代码、标签。
- 股数、摊薄成本、实时价。
- 当日涨跌幅、当日盈亏、持仓盈亏。
- 市值、当前仓位、目标仓位。
- 估值版本的 Upside、Forward PE、股东回报率。
- 加仓、减仓、编辑和交易历史。

## 6. 交易能力

### 6.1 开仓、加仓和减持

- 开仓支持中文、代码和拼音搜索。
- 加仓重算摊薄成本并扣减现金。
- 减持增加现金，按“剩余未回收本金”口径调整摊薄成本。
- 全部减持后删除持仓。
- 加仓、减持和调仓写入 `tradeHistory[]`。

### 6.2 调仓助手

- 卖出侧选择当前持仓，买入侧可选已持有或新股票。
- 支持 `1/5`、`1/4`、`1/3`、`1/2` 快捷数量。
- 一侧数量改变后，另一侧按金额和汇率估算。
- 两侧展示当前、本次和交易后仓位。
- 提交时一次更新持仓、现金和两条交易历史。

## 7. 编辑持仓和动态计划

左栏包含股票、摊薄成本、股数、当前仓位、估值版本、目标仓位和标签。右栏为加减仓计划：

- 初始至少 3 个买点和 3 个卖点。
- “添加买点 / 添加卖点”动态追加行并连续编号。
- 每行包含价格、Upside、Forward PE、股东回报率、股数、对应仓位和完成状态。
- 价格可正算指标，任一指标可反算价格和其余指标。
- 股数或价格变化时重算对应仓位。
- 新增行随组合 payload 保存，再次打开仍存在。
- 价格不得小于 0，股数必须是非负整数。

## 8. 标签、目标仓位和提醒

- 持仓可设置多标签，标签可重命名和筛选。
- 标签可维护组合级目标仓位，展示实际与目标偏差。
- 今日待操作使用当日高低价判断未完成点位是否触达。
- 触达后高亮对应加仓 / 减仓入口。

## 9. 隐私和数据同步

- 资产隐私开关隐藏资产和盈亏数字。
- 组合数据保存在 `portfolios.payload`，通过 Supabase RLS 按用户隔离。
- 交易历史、标签、目标仓位和买卖点是 payload 嵌套数据。
- 本地演示模式使用 Local Storage，不写生产库。

## 10. 净值

- 日终净值由 `daily-portfolio-nav` Edge Function 和 pg_cron 生成。
- 支持三个月、年初至今、指定年份和全部。
- 支持沪深300、恒生指数、恒生科技、标普500、纳指100。
- 指标包含区间收益、最大回撤和年化夏普比率。

## 11. 不在当前范围

- 券商自动同步。
- 佣金、税费、分红、利息和换汇独立流水。
- 计划行删除和拖拽排序。
- 组合对外分享。
- 历史净值自动回填。

## 12. 回归验收

- [ ] 开仓、加仓、减持和调仓后持仓与现金正确。
- [ ] 申购赎回前后净值不异常跳变。
- [ ] 估值预览和所有计划行指标正常。
- [ ] 旧股票缺少 `quoteId` 时仍能刷新市值。
- [ ] 新增第 4 个买点 / 卖点后保存和重开正常。
- [ ] 待操作、提醒点和完成状态一致。
- [ ] 隐私模式不泄露资产数字。
- [ ] 日终任务、曲线和基准数据正常。

# 组合管理需求文档

最后更新：2026-07-06  
文档状态：待 Review

## 1. 功能定位

在现有“股池”功能区旁新增一级功能区“组合管理”。

组合管理用于维护用户的实际仓位。用户可以创建多个组合，在组合内开仓、加仓、减持、查看仓位与资产汇总，并手动校准现金余额。

本期只实现本文明确描述的能力，不包含交易历史、分红、入金出金、目标仓位、收益曲线、券商同步和组合分享。

## 2. 页面结构

### 2.1 一级功能区

主导航包含：

- 股池
- 组合管理

“组合管理”与“股池”并列。点击“组合管理”进入组合管理页面。

### 2.2 组合切换区

页面展示当前用户创建的多个组合名称，并支持切换当前组合。

要求：

- 默认选中最近一次查看的组合。
- 首次使用且没有组合时，展示创建组合空状态。
- 提供“创建组合”按钮。
- 当前组合提供“删除组合”按钮。
- 切换组合后，刷新当前组合的汇总区、持仓列表和现金余额。

删除组合时需二次确认，并明确提示组合名称、持仓数量以及现金和持仓数据将一并删除且无法恢复。确认删除后自动切换到相邻组合；删除最后一个组合后进入创建组合空状态。

### 2.3 当前组合页面

页面由三部分组成：

1. 组合名称与组合切换区。
2. 资产汇总区。
3. 持仓列表区。

页面提供一个明显的“开仓”按钮。

## 3. 创建组合

### 3.1 入口

点击“创建组合”后打开创建组合弹窗或抽屉。

### 3.2 字段

#### 组合名称

- 必填。
- 同一用户下不可与已有组合重名。
- 建议限制为 1–30 个字符。

#### 账户类型

单选，必填：

- 人民币账户
- 港美账户

组合创建后，本期不支持修改账户类型。

#### 组合启动金额

启动金额由用户手动输入，用于计算组合净值。

人民币账户：

- 展示一个人民币金额输入框。
- 单位为万元人民币，保存时换算为人民币元。

港美账户：

- 展示港币金额输入框。
- 展示美元金额输入框。
- 单位分别为万港币和万美元，保存时换算为对应原币金额。
- 两项均允许输入 0。

### 3.3 创建结果

点击“创建”后：

- 生成组合。
- 启动金额同时作为组合的初始现金余额。
- 人民币账户的人民币现金余额等于人民币启动金额。
- 港美账户的港币、美元现金余额分别等于对应启动金额。
- 自动进入新创建的组合。
- 新组合的持仓列表为空。
- 净值初始为 1.0000。

### 3.4 校验

- 组合名称不能为空或重复。
- 金额必须为大于或等于 0 的数字。
- 启动金额折算成人民币后的合计必须大于 0。

## 4. 资产汇总区

汇总区展示以下指标：

### 4.1 净资产

`净资产 = 仓位市值 + 现金市值`

- 统一按人民币展示。
- 单位为万元。
- 汇总区金额四舍五入保留到整数万元。

### 4.2 仓位市值

`仓位市值 = 当前组合内全部股票市值之和`

- 所有股票市值均按当前汇率折算为人民币。
- 单位为万元。

### 4.3 现金市值

现金市值旁展示“校准现金”按钮。

人民币账户：

- 只展示人民币余额。
- 同时展示折算后的人民币现金市值。

港美账户：

- 分别展示港币余额和美元余额。
- 同时展示两种现金折算后的人民币现金市值合计。

计算规则：

- 人民币账户：`现金市值 = 人民币余额`
- 港美账户：`现金市值 = 港币余额 × 港币兑人民币汇率 + 美元余额 × 美元兑人民币汇率`

汇总区的现金市值以人民币万元展示，原币余额保留原币单位展示。

### 4.4 净值

`净值 = 净资产 / 组合启动金额`

净值的基准货币由账户类型决定：

- 人民币账户按人民币计算：全部股票和现金折算为人民币，除以人民币启动金额。
- 港美账户按美元计算：港股持仓和港币现金折算为美元，美股持仓和美元现金直接按美元计入。
- 人民币账户启动金额：用户创建组合时输入的人民币金额。
- 港美账户启动金额：港币启动金额按创建组合时的港币兑美元汇率折算为美元，再加上美元启动金额。
- 净值建议保留 4 位小数。
- 校准现金只改变当前净资产，不改变启动金额。

计算公式：

- 人民币账户：`净值 = 人民币净资产 / 人民币启动金额`
- 港美账户：`净值 = 美元净资产 / 美元启动金额`

为避免汇率变化导致净值分母持续变化，港美账户的启动金额应在创建组合时折算并保存为美元固定值，后续不随汇率变化。

## 5. 持仓列表

列表每一行代表当前组合中的一只股票。

### 5.1 列表字段

| 序号 | 字段 | 展示要求 |
| --- | --- | --- |
| 1 | 股票 | 股票名称 + 股票代码 |
| 2 | 股数 | 当前持有股数 |
| 3 | 摊薄成本 | 股票原货币单位的每股摊薄成本 |
| 4 | 市值 | 人民币账户按人民币万元展示；港美账户按美元展示 |
| 5 | 仓位比例 | 当前股票市值 / 组合净资产 |
| 6 | 操作 | 加仓、减持 |

### 5.2 股票市值

`股票原币市值 = 当前股数 × 股票最新价`

人民币账户：

`股票人民币市值 = 股票原币市值 × 对应人民币汇率`

港美账户：

- 港股：`股票美元市值 = 股票港币市值 × 港币兑美元汇率`
- 美股：原币市值即美元市值。

- A 股使用人民币。
- 港股使用港币。
- 美股使用美元。
- 人民币账户列表按人民币万元展示。
- 港美账户列表统一按美元展示，建议保留 2 位小数。
- 最新价沿用现有股票行情能力，并展示行情更新时间。

### 5.3 仓位比例

`仓位比例 = 当前股票基准货币市值 / 组合基准货币净资产 × 100%`

- 人民币账户的基准货币为人民币。
- 港美账户的基准货币为美元。
- 仓位比例的分母包含现金。
- 建议保留 2 位小数。

### 5.4 默认排序和空状态

- 默认按股票市值从高到低排序。
- 没有持仓时展示“暂无持仓”，并引导点击“开仓”。
- 减持后股数为 0 的股票从当前持仓列表移除。

## 6. 开仓

### 6.1 入口

点击组合页面的“开仓”按钮，打开开仓弹窗或抽屉。

### 6.2 字段

#### 股票代码

- 必填。
- 搜索与选择交互参考当前编辑股票时的股票搜索。
- 支持按股票名称或代码搜索。
- 选择后自动带出股票名称、代码、市场和原始交易币种。
- 如果该股票已存在于当前组合，不允许重复开仓，并提示使用“加仓”。

#### 买入价格

- 必填。
- 使用股票原货币单位：A 股为人民币、港股为港币、美股为美元。
- 必须大于 0。

#### 买入数量

- 必填。
- 必须大于 0。
- 本期按正整数股处理。

### 6.3 现金校验

`买入金额 = 买入价格 × 买入数量`

- A 股从人民币现金余额扣减。
- 港股从港币现金余额扣减。
- 美股从美元现金余额扣减。
- 现金余额不足时，不允许确认买入，并提示对应币种余额不足。
- 本期不计算佣金、印花税及其他交易费用。

### 6.4 确认开仓

点击“确认买入”后：

- 创建该股票持仓。
- 股数等于本次买入数量。
- 摊薄成本等于本次买入价格。
- 从对应币种现金余额中扣除买入金额。
- 关闭弹窗并刷新汇总区和持仓列表。

## 7. 加仓

### 7.1 入口

点击某只股票行的“加仓”按钮，打开加仓弹窗或抽屉。

### 7.2 字段

- 股票名称和代码：自动带入，只读，不可修改。
- 买入价格：用户输入，使用股票原货币单位，必须大于 0。
- 买入数量：用户输入，必须为正整数。

### 7.3 现金校验和扣减

- 买入金额等于买入价格乘以买入数量。
- 按股票所属币种扣除现金。
- 对应币种现金不足时不允许确认。

### 7.4 摊薄成本

确认加仓后重新计算摊薄成本：

`新摊薄成本 =（原股数 × 原摊薄成本 + 本次买入数量 × 买入价格）/（原股数 + 本次买入数量）`

同时：

- 新股数 = 原股数 + 本次买入数量。
- 对应币种现金余额扣减本次买入金额。
- 刷新股票市值、仓位比例和组合汇总。

## 8. 减持

### 8.1 入口

点击某只股票行的“减持”按钮，打开减持弹窗或抽屉。

### 8.2 字段

- 股票名称和代码：自动带入，只读。
- 卖出价格：用户输入，使用股票原货币单位，必须大于 0。
- 卖出数量：用户输入，必须为正整数，且不得超过当前股数。

### 8.3 确认减持

`卖出金额 = 卖出价格 × 卖出数量`

点击“确认减持”后：

- 当前股数扣除卖出数量。
- 卖出金额增加到股票对应币种的现金余额。
- 剩余股票的摊薄成本按回收本金口径重新计算：`新摊薄成本 =（原股数 × 原摊薄成本 − 卖出数量 × 卖出价格）/ 剩余股数`。
- 高于摊薄成本减持时，新摊薄成本下降；低于摊薄成本减持时，新摊薄成本上升。
- 当累计卖出回收金额超过原投入成本时，摊薄成本允许为负数。
- 刷新股票市值、仓位比例和组合汇总。
- 如果卖出全部股数，该股票从当前持仓列表移除。
- 本期不展示或累计已实现盈亏。
- 本期不计算佣金、印花税及其他交易费用。

## 9. 校准现金

### 9.1 入口

点击现金市值旁的“校准现金”按钮，打开校准现金弹窗。

### 9.2 默认值

弹窗自动带入当前组合现有的现金余额。

人民币账户：

- 展示人民币余额输入框。

港美账户：

- 展示港币余额输入框。
- 展示美元余额输入框。

### 9.3 保存

- 现金金额必须为大于或等于 0 的数字。
- 点击“保存”后，直接使用输入金额覆盖当前现金余额。
- 保存后关闭弹窗，并刷新现金市值、净资产、净值和所有仓位比例。
- 校准现金不改变组合启动金额。

## 10. 汇率与金额展示

- 系统需要提供港币兑人民币、美元兑人民币汇率。
- 港美账户还需要提供港币兑美元汇率，用于持仓列表和净值计算。
- 汇率能力沿用现有股池的汇率获取和兜底机制。
- 人民币账户以人民币为基准货币；港美账户以美元为基准货币。
- 页面展示金额时：人民币账户列表市值使用人民币万元；港美账户列表市值使用美元；原币现金余额和交易价格使用元、港元或美元。
- 摊薄成本建议保留 2–4 位小数；持仓列表人民币万元保留 2 位小数；汇总区人民币万元保留整数。

## 11. 关键数据

### 11.1 组合

- 组合 ID
- 用户 ID
- 组合名称
- 账户类型：人民币账户 / 港美账户
- 人民币启动金额
- 港币启动金额
- 美元启动金额
- 创建时折算的人民币启动金额
- 创建时折算的美元启动金额（港美账户净值计算的固定分母）
- 人民币现金余额
- 港币现金余额
- 美元现金余额
- 创建时间
- 更新时间

### 11.2 持仓

- 持仓 ID
- 组合 ID
- 股票名称
- 股票代码
- 市场
- 原始交易币种
- 当前股数
- 摊薄成本
- 创建时间
- 更新时间

本期持仓使用结果数据直接维护，不建设独立交易流水模块。

## 12. 权限要求

- 用户只能查看和修改自己的组合。
- 用户只能查看和修改自己组合中的持仓及现金。
- 数据库访问控制必须通过 RLS 校验当前用户身份。
- 组合和持仓信息不进入股池分享、关注、订阅及广场。
- 组合、现金和持仓数据保存到 Supabase，并在用户登录后跨浏览器、跨设备同步。
- 首次启用云端表且云端暂无组合时，自动将当前浏览器已有的本地组合上传到云端。

## 13. 验收标准

1. “组合管理”与“股池”作为并列功能区展示。
2. 用户可以创建多个组合并通过组合名称切换。
3. 创建人民币账户时只出现人民币启动金额输入框。
4. 创建港美账户时出现港币和美元两个启动金额输入框。
5. 新组合现金余额等于创建时输入的启动金额，初始净值为 1.0000。
6. 用户可以通过现有股票搜索完成开仓。
7. 开仓和加仓按股票原币种扣减现金，现金不足时不可提交。
8. 加仓后股数和摊薄成本按公式正确更新。
9. 减持后股数正确减少，卖出金额回到对应币种现金，摊薄成本按剩余本金公式正确更新，并允许为负数。
10. 全部减持后股票从当前持仓列表移除。
11. 人民币账户只展示人民币现金；港美账户分别展示港币和美元现金。
12. 校准现金会覆盖当前现金余额，但不会修改启动金额。
13. 净资产、仓位市值、现金市值、净值和仓位比例计算正确。
14. 人民币账户持仓列表市值按人民币万元展示；港美账户持仓列表市值按美元展示。
15. 人民币账户按人民币计算净值；港美账户按美元计算净值。
16. 用户之间的组合和持仓数据严格隔离。
17. 用户可以二次确认后删除组合，组合的现金和持仓数据同步删除，并自动切换到其他组合或空状态。

## 14. 本期明确不做

- 手续费和税费。
- 交易流水及交易记录查询。
- 已实现盈亏和未实现盈亏。
- 分红、入金、出金和换汇记录。
- 修改组合账户类型。
- 修改启动金额。
- 目标仓位及调仓建议。
- 净值历史曲线。
- CSV 导入导出。
- 券商账户同步。
- 组合公开分享。

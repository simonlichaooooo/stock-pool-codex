# 钞·作业产品需求

最后更新：2026-08-07
代码基线：`main`

## 1. 产品定位

钞·作业是面向个人投资研究和组合复盘的 Web 工具，把股票估值、实际持仓、研究日志和观点分享放在同一工作台内。产品提供研究与记录能力，不提供交易执行或投资建议。

## 2. 用户与权限

- 普通用户：维护私有股池、组合和日志；发布股池版本；关注发布者。
- 访客：通过公开链接查看允许公开的内容。
- 管理员：进行用户、股票和公开内容治理。
- 私有业务数据通过 Supabase RLS 按用户隔离；公开内容使用独立发布记录。

## 3. 产品模块

### 3.1 股池

- 按股票保存多个估值版本、假设、备注和数据来源。
- 支持 A 股、港股和美股搜索、行情及币种换算。
- 根据市值、利润、分红和回购等输入计算 Upside、Forward PE 和股东回报率。
- 支持版本状态、标签、排序、筛选、发布、复制和订阅。

### 3.2 组合管理

- 创建和切换多个人民币或港美账户组合。
- 管理现金、份额、持仓、目标仓位、标签和交易历史。
- 支持开仓、加仓、减持、换仓、智能调仓建议、申购、赎回和现金校准。
- 持仓关联股池估值版本，并维护动态买点和卖点。
- 展示盘中资产、当日盈亏、累计盈亏和日终净值。

完整规则见 [`PORTFOLIO_MANAGEMENT.md`](./PORTFOLIO_MANAGEMENT.md)。

### 3.3 市场洞察

- 以港股指数为入口，首期支持恒生科技指数 30 只成分股。
- 展示股票名称、周线 MA30 / MA40 / MA50 乖离率及近 2 年分位。
- 展示香港证监会合计须申报淡仓占已发行股份的估算比例，以及港股通日终持仓比例。
- 成分股、空头报告和港股通数据分别标注数据日期；缺数显示 `--`，不得按零值处理。
- 空头数据按周从证监会官方 CSV 更新；港股通当前快照按港交所使用条款合规维护。

### 3.4 日志

- 创建、编辑和删除研究日志。
- 支持股票提及、标签和筛选。
- 日志默认私有，与公开发布内容分离。

### 3.5 广场

- 浏览公开发布者和股池版本。
- 支持关注、复制和订阅。
- 复制生成独立快照；订阅保留对发布者版本的更新关系。

### 3.6 管理后台

- 管理用户、股票记录和公开内容。
- 管理员权限由后台数据与策略控制，不应只依赖前端显示判断。

## 4. 全局体验

- 顶部一级导航覆盖股池、组合管理、市场洞察、日志、广场和管理后台。
- 支持冰川蓝、星云紫、翡翠绿和琥珀暖色主题。
- 当前选中导航使用明显的玻璃态高亮；次级导航保持一致。
- 顶部邮箱脱敏展示；资产隐私开关隐藏组合金额和盈亏。
- 桌面端优先，同时保证窄屏下主要操作可用。

## 5. 数据与计算原则

- 金额计算必须携带币种和明确的换算时点。
- 运行时行情、汇率或市值缺失时显示降级状态，不伪造精度。
- 私有草稿与公开版本严格分离。
- 组合交易必须同时更新持仓、现金和交易历史。
- 申购赎回通过份额处理，避免外部现金流扭曲净值。

## 6. 当前不支持

- 券商交易执行和自动同步。
- 佣金、税费、分红、利息和换汇的完整独立流水。
- 组合公开分享和业绩归因。
- 历史净值自动回填。
- 完整自动化测试与 CI 回归。

## 7. 产品验收主路径

1. 登录、会话恢复和退出。
2. 股票新增、估值编辑、保存和发布。
3. 公开版本浏览、复制和订阅。
4. 组合创建、开仓、交易、动态计划和净值。
5. 市场洞察成分股、三组周线指标、空头和港股通快照。
6. 日志创建、股票提及和筛选。
7. 管理后台访问控制和基本治理。
8. 主题、隐私显示、桌面与窄屏布局。

## 8. 后续优先级

- P0：核心金融计算单元测试、交易与保存浏览器回归、发布烟雾测试。
- P1：拆分单文件、增加 payload schema version、完善任务监控和审计流水。
- P2：费用与分红、券商导入、组合分享和业绩归因。

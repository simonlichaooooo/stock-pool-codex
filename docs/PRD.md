# 钞·作业整体产品需求文档

- 文档版本：2.0
- 产品状态：核心功能已上线，市场数据历史回填持续进行
- 最后更新：2026-08-09
代码基线：`main@f3fe0c3`

## 1. 产品概述

### 1.1 产品定位

钞·作业是面向个人投资者的研究、估值、持仓管理和复盘工作台。产品把“研究一只股票—形成估值—纳入组合—制定买卖计划—跟踪市场信号—记录判断—分享研究”放在同一套数据体系内。

产品提供研究和记录工具，不提供证券交易执行、自动跟单或投资建议。

### 1.2 要解决的问题

- 股票研究、估值表、组合持仓和投资日志分散，难以保持口径一致。
- 估值结论与实际仓位、买卖价格之间缺少联动。
- 组合收益容易被申购赎回等外部现金流扭曲。
- 批量观察股票周期位置、空头和港股通资金变化成本较高。
- 公开观点与个人私有草稿容易混在一起，缺少可控的分享与订阅机制。

### 1.3 产品目标

1. 让用户用统一模板维护多市场股票估值。
2. 将股池估值与组合仓位、动态买卖计划关联。
3. 用份额法记录组合净值，隔离外部现金流影响。
4. 用乖离率、指数相对收益和持仓数据提供研究线索。
5. 保留每次研究判断及当时价格，支持事后复盘。
6. 在不暴露私有数据的前提下发布、关注、复制或订阅研究成果。

### 1.4 成功标准

- 用户能独立完成“新增股票—录入估值—加入组合—设置买卖点—记录日志”的完整闭环。
- 核心金额、收益率、净值和乖离率计算有明确公式，缺数不伪造结果。
- 私有草稿、组合资产和日志按用户隔离，公开内容均由用户主动发布。
- 自动市场数据任务可追溯、可重跑，页面能明确展示数据日期和空值。

## 2. 用户与权限

### 2.1 用户角色

| 角色 | 权限 |
| --- | --- |
| 登录用户 | 管理自己的股池、组合和日志；发布股票研究；关注、复制和订阅他人股池 |
| 公开访客 | 通过允许公开的入口浏览发布者及公开研究，不得读取私有草稿和资产 |
| 管理员 | 查看用户及公开股票，隐藏违规公开内容，限制用户分享，维护治理备注 |
| 本地演示用户 | 使用浏览器本地演示数据体验主流程，不写入生产数据库 |

### 2.2 权限原则

- Supabase Auth 支持 GitHub OAuth 和 Email Magic Link。
- 私有业务表通过 RLS 按 `user_id` 隔离。
- 公开发布使用独立发布状态和版本记录，不直接开放用户私有 payload。
- 管理员权限必须由后台数据和数据库策略共同校验，不能只靠前端隐藏按钮。
- 浏览器只能使用 Supabase anon key；Service Role Key、Cron Secret 不得进入前端或仓库。
- 资产隐私开关只隐藏页面金额，不替代数据库权限。

## 4. 全局产品要求

### 4.1 会话与初始化

- 支持登录、会话恢复和退出。
- 登录后加载用户档案、股池、关注关系、组合、日志及管理员状态。
- 单个模块数据失败时不应阻断其他模块进入；页面需显示对应降级提示。
- 演示模式与生产用户数据严格分离。

### 4.2 导航与视觉

- 当前一级导航具有明确高亮，所有模块沿用一致的蓝白玻璃质感。
- 支持冰川极光、星云紫、翡翠潮汐、琥珀晨光主题。
- 桌面端优先，窄屏下核心阅读、搜索、保存和交易操作仍可用。
- 表格数值使用稳定列宽和等宽数字；正负值颜色语义一致。
- 加载、空数据、部分失败和完全失败必须有不同状态。

### 4.3 搜索与代码规范

- A 股、港股、美股支持名称、代码和常用别名搜索；适用位置支持拼音。
- 港股名称优先显示简体中文，代码统一规范化。
- 价格、市值、汇率均需携带更新时间；缺数显示 `--`，不得展示为零。

### 4.4 金融数据原则

- 金额必须携带币种，跨币种计算必须明确汇率和基准币。
- 外部行情失败时可回退最近成功值，但必须保留更新时间。
- 计算的估算值、供应商值和官方值应通过字段或质量状态区分。
- 历史比例必须使用对应日期有效分母，不得默认用当前股本倒算并冒充官方结果。

## 5. 股池

### 5.1 功能定位

股池是股票研究和估值的主数据入口。每只股票可保存多个估值版本，供列表比较、组合关联、公开发布和后续复盘。

### 5.2 股票与版本

- 支持 A 股、港股和美股。
- 同一股票可以有多个估值版本，例如悲观、中性、乐观或按年份保存的版本。
- 记录股票名称、代码、市场、交易所、币种、估值版本、更新时间和来源。
- 用户可新增、编辑、删除、拖拽排序和上下移动。
- 支持市场筛选、名称/代码/别名搜索、已分享筛选。
- 订阅来源删除后保留降级提示，不继续展示无效计算结果。

### 5.3 估值输入

核心输入包括：

- 最新市值及原始币种；
- 预测年份、前瞻利润和前瞻 PE；
- 净现金和现金折扣系数；
- 预期分红、回购及股东回报；
- 估值、利润、现金和股东回报相关备注；
- 可选的分部估值明细。

输入可保留原币金额，系统统一折算为人民币亿元进行列表比较。行情和市值刷新不得覆盖用户的估值假设。

### 5.4 核心公式

```text
前瞻市值 = 前瞻利润 × 前瞻 PE + 净现金 × 现金折扣
Upside = 前瞻市值 / 最新市值 - 1
Forward PE = (最新市值 - 净现金 × 现金折扣) / 前瞻利润
股东回报率 = 前瞻股东回报 / 最新市值
股息率 = 预期分红 / 最新市值
回购率 = 预期回购 / 最新市值
```

- 分母为零或必要输入缺失时结果为空。
- 港股通红利税开关启用时，港股列表股东回报率中的分红按 80% 计入，回购不折减。
- 列表支持 Upside、Forward PE、股东回报率、股息率、回购率、30 周乖离率和 2 年分位值排序。

### 5.5 乖离指标与四类提醒

股池和组合统一使用 30 周乖离率：

`30 周乖离率 = (最新周收盘价 / 最近 30 周收盘价算术平均值 - 1) × 100%`

近 2 年分位使用最近 104 个有效周度乖离率，按中秩百分位计算；不足 104 个有效观察值时不展示。

提醒规则：

| 类别 | 条件 | 产品提示 |
| --- | --- | --- |
| 弱周期极端位置 | 30 周乖离率 `< -30%`，或 2 年分位 `< 10%` | 观察基本面转折信号 |
| 强周期极端位置 | 30 周乖离率 `> 30%`，或 2 年分位 `> 90%` | 观察赔率空间和基本面转弱信号 |
| 叙事展开期 | 最近 3 个周度乖离率严格递增 | 观察基本面变化趋势 |
| 叙事压缩期 | 最近 3 个周度乖离率严格递减 | 观察叙事和基本面降温 |

- 相等不属于严格递增或严格递减。
- 同一股票可以同时命中一个极端位置提醒和一个趋势提醒。
- 乖离率或分位数据无效时不进入提醒。

### 5.6 发布、复制和订阅

- 用户可主动分享股票估值，并维护公开版本历史和变更说明。
- 复制生成与来源脱离的独立股票记录。
- 订阅保留来源关系，可接收发布者后续更新。
- 订阅股票可取消订阅或转换为自己的独立股票。
- 私有修改不会自动成为公开内容；发布必须是显式操作。

## 6. 组合管理

### 6.1 功能定位

组合管理用于维护真实或模拟持仓、现金、交易计划、份额和净值。组合数据独立于股池，但持仓可以关联一个股池估值版本。

完整业务规则见 [`PORTFOLIO_MANAGEMENT.md`](./PORTFOLIO_MANAGEMENT.md)。

### 6.2 账户与组合

| 账户类型 | 可用市场 | 现金币种 | 净值基准币 |
| --- | --- | --- | --- |
| 人民币账户 | A 股、港股通 | CNY | CNY |
| 港美账户 | 港股、美股 | HKD、USD | USD |

- 支持创建、初始化导入、切换、重命名和删除多个组合。
- 同一用户组合名称不可重复，删除必须二次确认。
- 初始化金额同时建立现金、启动资产、总份额和初始单位净值。
- 支持普通股票及期权持仓；期权展示方向、合约数、市值和名义敞口。

### 6.3 持仓和交易

- 持仓展示股数、摊薄成本、实时价、当日涨跌、当日/持仓盈亏、市值或敞口、仓位、目标仓位、估值和乖离指标。
- 支持开仓、加仓、减持/平仓、换仓和编辑持仓。
- 买入必须通过对应现金余额校验，卖出不得超过持仓数量。
- 加仓重新计算摊薄成本；减持回收现金并按剩余未回收本金调整摊薄成本。
- 全部卖出后移除持仓；换仓同时写入卖出和买入历史。
- 每次交易必须同步更新持仓、现金和交易历史，任何一步失败不得留下半完成状态。

### 6.4 估值联动与动态计划

- 持仓可选择同股票的一个股池估值版本。
- 每个持仓至少支持 3 个买点和 3 个卖点，并可继续追加。
- 每行包含价格、Upside、Forward PE、股东回报率、股数、对应仓位、备注和完成状态。
- 输入价格可正算三个估值指标；输入任一指标可反算价格及其他指标。
- 价格或股数变化时同步重算计划对应仓位。
- 所有新增计划行随组合保存，逻辑不得假设固定只有 3 行。

### 6.5 标签、目标仓位和调仓建议

- 持仓支持多标签，标签支持重命名、筛选和组合级目标仓位。
- 个股可设置目标仓位；设为 0% 时不显示目标偏离提醒。
- 调仓建议综合标签目标、个股上限、可用现金、估值版本、动态买卖点和交易单位。
- 建议分为“现在执行”和“等待条件”，展示调整前后标签偏差、预计换手率及有效估值覆盖。
- 无法同时满足约束时必须明确提示，不得伪造可执行方案。
- 今日待操作根据当日最高/最低价判断未完成买卖点是否触达。

### 6.6 份额和净值

```text
净资产（基准币）= 持仓市值 + 现金
单位净值 = 净资产 / 总份额
申购或赎回份额 = 原币金额折算基准币 / 操作前单位净值
```

- 申购增加现金和份额；赎回减少现金和份额。
- 赎回不得超过现金，不允许赎回全部份额。
- 现金校准直接覆盖余额、不改变份额，差额计入组合收益。
- 日终任务生成组合净值和基准数据；盘中展示估算净值并明确标记。
- 支持近三个月、年初至今、指定年份和全部范围。
- 支持沪深 300、恒生指数、恒生科技、标普 500、纳指 100 基准。
- 展示区间收益、最大回撤和年化夏普比率，当前无风险利率按 0 处理。
- 提供日、周、月收益日历和净值明细。

## 7. 市场洞察

### 7.1 功能定位

市场洞察把港股指数成分、周线位置、空头持仓和港股通持仓集中展示，用于快速发现值得进一步研究的股票。

完整产品和数据规则见：

- [`MARKET_INSIGHTS_PRD.md`](./MARKET_INSIGHTS_PRD.md)
- [`MARKET_INSIGHTS_HANDOFF.md`](./MARKET_INSIGHTS_HANDOFF.md)

### 7.2 指数与列表

- 支持恒生科技、恒生综合大型股、中型股和小型股。
- 默认按指数权重降序；没有公开完整权重时按官方名单顺序。
- 支持股票名称/代码搜索、跨指数匹配、全量排序和每页 50 只分页。
- 展示 5 周超额收益，5/30/40/50 周乖离率及近 2 年分位值，空头持仓比例和港股通持仓比例。
- 所有数值列支持升降序，排序针对全部结果后再分页，缺失值置后。

### 7.3 星级评选

每符合一项获得 1 星：

1. 5 周超额收益为正。
2. 5 周乖离率为正。
3. 30、40、50 周乖离率全部为正。
4. 5 周空头持股数下降。
5. 5 周港股通持股数增加。

提供 3 星、4 星和 5 星筛选。名称区始终展示总星级；列表中的单项正向条件显示提示星。星级使用持股数变化，不依赖历史比例是否完整。

### 7.4 详情

- 支持 2 年、1 年和今年以来。
- 乖离率图展示 5/30/40/50 周线，5 周使用虚线；悬停展示乖离率和对应 2 年分位值。
- 空头和港股通图展示历史比例及区间趋势提示。
- 部分数据源失败时保留可用图表；无有效分母时不生成比例。

### 7.5 数据边界

- 空头来自 SFC 合计须申报淡仓，未披露不代表零。
- 港股通来自 HKEX 官方南向聚合数据，当前可信生产历史从 2025-08-11 开始。
- 比例分母优先使用港交所翌日披露报表，其次使用月报表，并剔除库存股。
- 2023—2024 年旧的单通道港股通数据已归档，不参与页面和评星。

## 8. 日志

### 8.1 功能定位

日志用于记录投资判断及当时市场状态，默认仅本人可见。

### 8.2 功能规则

- 支持创建、编辑和删除日志，正文最长 30,000 字。
- 在正文输入 `$` 后可按股票名称或代码搜索并插入股票。
- 发布时记录被提及股票的当时价格；旧日志缺价时可进行补全。
- 日志按时间倒序展示，长正文支持展开和收起。
- 支持按月份和提及股票筛选，并显示各筛选项数量。
- 股票名称按当前主数据规范化，但保留代码用于稳定关联。
- 删除需确认且不可恢复。
- 数据库未部署时明确提示；已有本地日志可迁移到数据库。

## 9. 广场与研究共享

### 9.1 广场

- 只展示允许公开且未被管理员隐藏的发布者。
- 支持按发布者昵称搜索，并按最近发布或发布数量排序。
- 卡片展示发布数量、最近发布时间及最多 3 只代表股票。
- 用户可进入发布者股池查看公开估值。

### 9.2 关注与共享入口

- 用户需设置唯一昵称和分享可见性。
- 支持关注和取消关注发布者。
- 股池中可以切换查看已关注发布者的公开股票。
- 外部分享链接需先校验发布者和可见性，再进入公开股池。
- 发布者被禁用分享或内容被隐藏后，访客不得继续读取对应公开内容。

## 10. 管理后台

- 仅管理员可访问。
- 展示用户昵称、邮箱、分享可见性、股池数量和治理状态。
- 支持将用户从广场隐藏或恢复。
- 支持禁用或恢复用户分享能力。
- 支持维护管理员备注。
- 支持查看用户股票的公开状态、最新市值、Upside、Forward PE 和发布时间。
- 支持隐藏或恢复单条公开股票。
- 治理操作应落库并受后台权限保护。

### 11.1 主要数据域

| 数据域 | 主要对象 |
| --- | --- |
| 用户与权限 | `profiles`、Supabase Auth、管理员字段 |
| 股池 | `stock_records`、`stock_publications`、订阅关系 |
| 社交 | `follows`、公开发布者与可见性 |
| 组合 | `portfolios`、`portfolio_cash_flows`、`portfolio_daily_nav` |
| 日志 | `journal_entries` |
| 市场洞察 | 指数成分、周线指标、SFC 空头、HKEX 港股通、官方历史股本 |
| 任务审计 | `market_data_ingestion_runs`、GitHub Actions 日志 |

### 11.2 外部数据与降级

- 股票搜索与行情：腾讯、东方财富和本地目录互为降级。
- 汇率：外部汇率接口，失败时保留最近成功值和更新时间。
- 指数成分：恒生指数公司公开资料。
- 空头：香港证监会 SFC。
- 港股通和历史股本：香港交易所 HKEX。
- 外部数据失败不得阻止用户读取已保存研究和组合。
- 所有自动任务应支持幂等写入、分批执行、断点重跑和错误追踪。

### 11.3 安全与隐私

- 私有数据默认拒绝跨用户读取。
- 生产密钥不得进入 Git、前端和错误提示。
- 日志、股池草稿和组合不得因分享股票而连带公开。
- 公开内容复制后成为新用户的独立数据；订阅内容必须保留来源标记。
- 删除、发布、交易、现金校准等高影响操作需要确认或明确保存动作。

### 11.4 性能与可靠性

- 常规主页面目标 5 秒内可交互，外部接口异常时 15 秒内给出失败或降级提示。
- 市场洞察应读取持久化周线指标，不得在首屏逐只计算 500 余只股票。
- GitHub Pages 发布失败不得影响上一版线上页面。
- Supabase 数据库变更与前端发布是独立流程；涉及 SQL 的功能必须完成数据库部署后才能验收。

## 12. 已知限制

- 前端集中在单个 `index.html`，模块耦合和回归成本较高。
- 股池和组合主体使用 JSONB payload，尚无完整 schema version 和数据库级字段约束。
- 尚未完整建模佣金、税费、分红、利息、换汇和现金校准审计流水。
- 尚未对接券商，交易和持仓依赖用户维护。
- 组合净值没有自动历史回填，组合暂不支持公开分享和完整业绩归因。
- 市场洞察官方历史股本仍在回填，少数公告需要人工核验。
- 2025-08-11 之前缺少完整免费的官方港股通逐股历史。
- 核心金融计算和浏览器主路径尚未达到完整自动化测试覆盖。

## 13. 整体验收标准

### 13.1 账户与隔离

- [ ] 登录、会话恢复、退出和演示模式正常。
- [ ] 用户 A 无法读取或修改用户 B 的股池、组合和日志。

- [ ] 发布、版本历史、复制、订阅、取消订阅和转为自己的股票正常。

### 13.3 组合管理

- [ ] 开仓、加仓、减持、平仓和换仓后的持仓、现金与交易历史一致。
- [ ] 申购赎回不引起单位净值异常跳变。
- [ ] 估值联动和新增第 4 个及以后买卖计划保存正常。
- [ ] 标签目标、调仓建议、今日待操作和隐私模式正常。
- [ ] 日终净值、基准曲线、指标、收益日历和明细正常。

### 13.4 市场洞察

- [ ] 四个指数的成分、默认顺序、搜索、全量排序和分页正确。
- [ ] 周线指标、近 2 年分位和 5 周超额收益与数据库一致。
- [ ] 5 项星级规则及 3/4/5 星筛选正确。
- [ ] 三张详情图、三个时间范围、悬停信息和空状态正确。
- [ ] 空头及港股通数据日期、分子、官方股本分母和质量状态可追溯。

### 13.5 日志、广场和后台

- [ ] 日志新增、编辑、删除、股票提及、价格记录和筛选正常。
- [ ] 广场只展示允许公开的发布者，搜索和排序正确。
- [ ] 分享链接、关注、股池切换以及管理员隐藏/恢复行为符合权限。

### 13.6 跨端与发布

- [ ] 四套主题、桌面和窄屏核心路径可用。
- [ ] 外部行情失败时已保存数据仍可读取，空值和错误状态清晰。
- [ ] 前端、SQL、Edge Function 和 GitHub Actions 分别完成部署及烟雾验证。

## 14. 版本路线图

### P0：准确性与稳定性

- 完成官方历史股本回填和市场洞察数据覆盖率审计。
- 为估值、摊薄成本、份额、净值、外汇和乖离率增加单元测试。
- 增加股池保存、组合交易、发布和市场洞察浏览器回归。
- 建立 GitHub Pages、日终净值和市场数据任务失败告警。

### P1：架构与审计

- 将单文件前端拆分为样式、数据访问和业务模块。
- 为股池与组合 payload 增加 schema version、验证和迁移。
- 将交易、现金校准、费用、分红、利息和换汇迁移为可审计流水。
- 增加市场数据质量状态的前端展示。

- 券商数据导入与持仓对账。
- 组合公开分享、业绩归因和历史净值回填。

- 增加更多指数、市场和研究指标。

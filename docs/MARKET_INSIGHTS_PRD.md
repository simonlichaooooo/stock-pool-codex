# 市场洞察 PRD

- 文档版本：1.0
- 产品状态：已上线，官方历史股本仍在分年度回填
- 最后更新：2026-08-09
适用范围：港股市场洞察列表、星级评选与股票详情页

## 1. 背景与目标

市场洞察用于把港股指数成分、周线位置、空头持仓和港股通持仓放在同一个分析视图中，帮助用户快速完成以下判断：

- 股票相对所属指数是否取得超额收益；
- 股价位于中长期均线的什么位置，当前水平在近两年处于什么分位；
- 可申报空头持仓是否下降；
- 港股通持股是否增加；
- 哪些股票同时满足多个积极条件，值得优先查看详情。

产品强调“发现线索”，不构成投资建议。空头披露并不代表市场全部空头，港股通持仓也不代表全部机构资金。

## 2. 用户与核心场景

目标用户为关注港股、需要按指数批量观察趋势和资金持仓的个人投资者。

核心场景：

1. 在恒生科技、大型股、中型股、小型股中切换并浏览成分股。
2. 按指数权重、乖离率、超额收益或持仓比例寻找靠前股票。
3. 通过 3 星、4 星、5 星快速筛选同时满足多个条件的股票。
4. 搜索股票名称或代码，并跳转到该股票所在指数。
5. 查看单只股票近两年、一年或今年以来的指标走势。

## 3. 产品范围

### 3.1 本期范围

- 四个指数：恒生科技指数、恒生综合大型股指数、恒生综合中型股指数、恒生综合小型股指数。
- 市场洞察列表、搜索、排序、分页和星级筛选。
- 乖离率、空头持仓比例、港股通持仓比例详情图。
- 周线指标和持仓数据持久化。
- 官方数据的自动更新、历史回填、数据质量标记和失败重跑。

### 3.2 非本期范围

- 买卖建议、目标价和自动交易。
- 恒生指数公司未公开的完整实时权重授权数据。
- 2025-08-11 之前的完整官方港股通历史；后续可评估港交所付费数据或持牌供应商。
- 将 SFC 未披露的空头仓位推算为零。
- 在官方股本缺失时伪造“官方比例”。

## 4. 信息架构

入口位于主导航“市场洞察”。页面由四部分组成：

1. 顶部操作区：指数切换、股票搜索、刷新数据。
2. 星级评选区：规则说明、全部/5 星/4 星/3 星筛选。
3. 数据列表：成分股及最新指标，默认每页 50 只。
4. 股票详情：三张历史走势图和时间范围筛选。

## 5. 功能需求

### 5.1 指数切换

| 产品文案 | 指数代码 | 指数全称 |
| --- | --- | --- |
| 恒生科技 | `HSTECH` | 恒生科技指数 |
| 大型股 | `HSLI` | 恒生综合大型股指数 |
| 中型股 | `HSMI` | 恒生综合中型股指数 |
| 小型股 | `HSSI` | 恒生综合小型股指数 |

要求：

- 采用平铺标签，不使用下拉框。
- 切换指数后重置页码，并展示对应指数成分和数据日期。
- 股票名称统一显示简体中文；代码统一显示为 `00000.HK` 形式。
- 默认按指数权重降序排列；缺少公开权重时按官方成分名单顺序，仍缺失时才使用稳定原始顺序。

### 5.2 搜索

- 支持简体股票名称、别名、四/五位股票代码和 `.HK` 代码搜索。
- 优先过滤当前指数；当前指数无结果时展示跨四个指数的匹配建议。
- 选择跨指数结果后，自动切换指数并定位该股票。
- 搜索和星级筛选可叠加，搜索结果仍按当前排序规则排列。

### 5.3 列表

列表字段顺序如下：

| 字段 | 展示要求 |
| --- | --- |
| 股票名称 | 第一行简体名称；第二行代码和总星级 |
| 5 周超额收益 | 百分比，正值显示正号；符合规则时显示提示星 |
| 5 周乖离率 | 乖离率和近 2 年分位值；正值显示提示星 |
| 30 周乖离率 | 乖离率和近 2 年分位值；正值显示提示星 |
| 40 周乖离率 | 乖离率和近 2 年分位值；正值显示提示星 |
| 50 周乖离率 | 乖离率和近 2 年分位值；正值显示提示星 |
| 空头持仓比例 | 第一行最新比例，第二行展示“5周增持/减持 x.xx%”；表头小字为 `SFC`；满足 5 周下降规则时显示提示星 |
| 港股通持仓比例 | 最新比例；表头小字为 `HKEX 日终数据`；满足 5 周增加规则时显示提示星 |
| 操作 | “查看详情” |

交互要求：

- 每页 50 只，先对全部结果排序，再分页。
- 5 周超额收益、5/30/40/50 周乖离率、空头比例、港股通比例均支持升序和降序。
- 缺失值始终排在有效值之后；相同值按原成分顺序保持稳定。
- 无数据展示 `--`，不得把缺失数据展示为 `0`。
- 空头 5 周变化按 `最新空头持仓比例 - 5 周前空头持仓比例` 计算；正数显示“增持”，负数显示“减持”，文案只展示比例差的绝对值并保留 `%` 单位；历史比例不足时显示“5周变化 --”。
- “刷新数据”加载数据库持久化指标和最新持仓，不得对数百只股票逐只临时请求周线行情。

### 5.4 星级评选

每符合一项获得 1 星，满分 5 星：

1. 5 周超额收益大于 0。
2. 5 周乖离率大于 0。
3. 30、40、50 周乖离率全部大于 0。
4. 5 周空头持仓下降：5 周前空头股数减最新空头股数大于 0。
5. 5 周港股通持仓增加：最新港股通持股数减 5 周前持股数大于 0。

补充规则：

- 规则 3 只贡献 1 星；但列表中 30、40、50 周任一乖离率为正时，该单元格各自显示一颗提示星。
- 不启用星级筛选时，名称区仍显示总星级，符合单项的数值左侧仍显示提示星。
- 提供全部、5 星、4 星、3 星平铺筛选；1 星和 2 星不提供独立筛选入口。
- 星级以持股数变化计算，不依赖历史比例是否已补齐。
- 任一规则所需数据缺失时，该项不得判定为满足。

### 5.5 股票详情

详情页支持 `2年`、`1年`、`今年以来` 三个时间范围，并包含：

1. 乖离率走势：展示 5、30、40、50 周乖离率；5 周线使用虚线。鼠标悬停时展示同一日期四个乖离率及各自近 2 年分位值，分位值不单独绘制曲线。
2. 空头持仓比例走势：展示 SFC 周度可申报空头股数占有效已发行股本比例。
3. 港股通持仓比例走势：展示港交所官方南向持股数占有效已发行股本比例。

若部分数据源失败，成功数据仍需展示，并提示“部分历史数据加载失败”。无有效比例时展示空状态，不使用当前股本悄悄替代历史官方分母。

## 6. 指标定义

### 6.1 周线和乖离率

- 周线收盘价来自周度行情。
- `N 周 MA = 最近 N 个周收盘价的算术平均值`。
- `N 周乖离率 = (本周收盘价 / N 周 MA - 1) × 100%`。
- N 取 5、30、40、50。

### 6.2 近 2 年分位值

- 使用截至该周最近 104 个有效周度乖离率样本。
- 少于 104 个有效样本时分位值为空。
- 同值采用中位秩：`(小于当前值的数量 + 0.5 × (等于当前值的数量 - 1)) / (样本数 - 1)`。

### 6.3 5 周超额收益

- 股票 5 周收益：本周收盘价相对 5 个周度区间前收盘价的累计涨跌幅。
- 指数 5 周收益：所选指数同期累计涨跌幅。
- `5 周超额收益 = 股票 5 周收益 - 指数 5 周收益`。
- 指数官方周线不可用时，可使用指数成分股同期等权收益作为降级值，并保存质量标记，不得标记为官方指数收益。

### 6.4 空头持仓比例

`空头持仓比例 = SFC 合计须申报淡仓股数 / 对应日期有效已发行股份数 × 100%`

- 分子来自香港证监会周度 Aggregated Reportable Short Positions。
- 分母优先采用港交所翌日披露报表，其次采用月报表；库存股从有效分母剔除。
- SFC 未出现某股票只表示未披露，不得解释为持仓为零。

### 6.5 港股通持仓比例

`港股通持仓比例 = 港交所官方南向合计持股数 / 对应日期有效已发行股份数 × 100%`

- 分子为港交所官方聚合页中中国结算两个 CCASS 参与者的日终合计持股。
- 当前可信生产数据从 2025-08-11 开始，`completeness = official_aggregate`。
- 旧的单通道、不完整数据已从生产表归档，不参与比例和评星。

### 6.6 官方历史股本优先级

1. 港交所翌日披露报表，优先级 100。
2. 港交所月报表，优先级 80。
3. 持牌供应商或旧推算数据只作兼容兜底，不得覆盖更高优先级官方记录。

只有成功解析且通过股数校验的官方记录才可用于覆盖。H 股、不同投票权股份、REIT 上市单位、双柜台和库存股必须按对应上市股份类别处理。

## 7. 数据源与更新频率

| 数据 | 来源 | 频率/时间 | 生产边界 |
| --- | --- | --- | --- |
| 指数成分与公开权重 | 恒生指数公司公开资料 | 周五 18:00 香港时间刷新快照 | 权重缺失时保留官方顺序 |
| 周线行情与指标 | 腾讯/东方财富周线，计算后入库 | 周五 19:00 香港时间 | 指标自 2023 年起持久化 |
| 空头持仓 | 香港证监会 SFC | 周五 18:00 香港时间 | 周度，披露有门槛和滞后 |
| 港股通持仓 | 港交所官方南向聚合数据 | 工作日 20:00，回看 10 天 | 免费在线窗口约 12 个月；当前从 2025-08-11 |
| 官方历史股本 | 港交所月报表、翌日披露报表 | 周五回看最近 70 天；历史按年份回填 | 2023 至今，覆盖率以数据库核验为准 |

## 8. 状态与异常体验

- 初始加载：显示“正在读取市场数据”，保留已加载页面骨架。
- 手动刷新：按钮进入“刷新中”，禁止重复提交。
- 部分失败：列表保留可用字段，错误信息应说明失败阶段。
- 全部失败：保留成分股和股票名称，指标展示 `--`，提供再次刷新。
- 历史图为空：区分“无披露”“股本分母缺失”“接口失败”，不得统一解释为零。
- 日期：页面必须展示成分生效日、空头报告日和港股通持仓日。

## 9. 非功能要求

- 列表正常读取数据库缓存，不应为 500 余只股票逐只请求行情。
- 单个指数常规首屏目标在 5 秒内完成；数据库或网络异常时 15 秒内给出明确失败提示。
- 全量排序、搜索和星级筛选在客户端完成时不阻塞交互。
- 自动任务支持幂等 upsert、分批执行和断点重跑。
- Service Role Key 仅用于 GitHub Actions，不得下发浏览器；浏览器按 Supabase RLS 读取。
- 外部来源、数据日期、质量和公告链接需可追溯。

## 10. 验收标准

1. 四个指数均能打开，数量与最新成分快照一致，默认顺序符合权重/官方顺序。
2. 搜索“美图公司”或 `1357` 能返回并定位对应股票。
3. 全部七个数值字段可升降序；跨页排序正确；缺失值在末尾。
4. 星级计算逐项符合第 5.4 节，筛选数与列表结果一致。
5. 周线数据已持久化时，列表不触发逐股实时周线计算。
6. 详情页三个时间范围生效，5 周乖离率为虚线，悬停显示乖离率和分位值。
7. 空头和港股通比例只在分子、历史有效股本均存在时展示。
8. 港股通生产数据不存在 `partial_sh`、`partial_sz`，2025-08-11 前旧数据不参与当前结果。
9. 官方股本解析失败不会覆盖已有高质量数据，并能从公告编号追溯失败原因。
10. 定时任务失败时页面保留上一版成功数据，运维人员可按 Handoff 重跑。
